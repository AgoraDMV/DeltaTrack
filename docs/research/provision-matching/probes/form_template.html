Examples

Picking an answer sets confidence to high, so a clear-cut card is one click. Change it when the card is not clear-cut: medium and low both require a rationale, and low flags the pair for a second look. You cannot move to the next card until the current one has everything it needs.

Download often. Your answers autosave, but only into this browser's storage on this machine — they are not a file yet. Clearing browsing data, resetting or switching browser profile, or a privacy setting that discards site data for local files takes every answer you have not downloaded with it. Downloading is the only durable copy; the header shows how many answers are not in a downloaded file yet. Downloading partway is expected — send the last file when you finish.
